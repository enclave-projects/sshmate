# Workspace preview

`workspace.png` is rendered by `test/workspace_flow_test.dart` at 1280 × 900 logical pixels using the real Flutter widget tree, Windows Segoe UI and Material Icons. It shows only disposable test fixtures with documentation IP addresses. No account data, copied Termius graphics or private credentials appear in the image.

Regenerate on Windows:

```powershell
flutter test test/workspace_flow_test.dart
```

The widget test also exercises host validation/editing, tags, grouping, favorites, search, identity creation, snippet creation, filters, settings navigation and a smaller window. This rendered preview is not a screenshot of a live SSH connection or proof of exact visual parity with Termius.

`workspace-light.png` is the same fixture workspace rendered with the Workbench light theme. Both previews are regenerated by the workspace flow test.
