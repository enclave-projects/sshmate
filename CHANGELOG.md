# Changelog

Notable user-facing changes are recorded here for each release.

## 0.2.0 — 2026-10-20

- Introduced the Workbench design system with dark and light themes, clearer focus and hover states, improved host cards and more legible settings.
- Added actionable empty states, vault password visibility, improved validation, accessible notices and clearer terminal/SFTP progress feedback.
- Added compact navigation coverage, light-theme previews and design-system component checks.
- Added Windows GitHub Actions workflow and contributor/issue-reporting guidance.
- Added regression coverage for reduced motion, keyboard activation and semantic error feedback.

## 0.1.1 — 2026-10-19

- Fixed Windows terminal text input attachment by supplying Flutter's containing view ID.
- Improved terminal focus after connection, SFTP and session-tab changes.
- Expanded real-input SSH acceptance coverage.
