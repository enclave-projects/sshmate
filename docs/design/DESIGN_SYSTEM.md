# Workbench — SSH Mate design system

Workbench is an original desktop design language for SSH Mate. It favors clear actions, stable layouts and readable server details. The implementation is `lib/ui/theme.dart` and `lib/ui/design_system.dart`.

## Foundations

- **Color:** dark canvas #111820, raised surface #1A2430, blue accent #8DBAFF. Light mode uses #F5F7FA with #235CA5 actions. Use `ColorScheme` semantic roles for content, feedback and focus, rather than assuming a dark background.
- **Typography:** Segoe UI for controls; Consolas for commands. Page titles 30 px, section titles 21 px, body 14 px, secondary details 12 px. Labels accompany important icons.
- **Space:** 4, 8, 16, 24 and 32 px (`MateSpace`). Page gutters 28 px, control radius 10 px, independent host surface radius 14 px. Prefer spacing and dividers over nested cards.
- **Controls:** minimum 44 px primary buttons; visible input borders, a 2 px focus outline, descriptive tooltips and keyboard access. Destructive confirmations use the error role.
- **Motion:** 160 ms hover/focus transitions; no layout movement. `MateMotion` disables these transitions when the platform requests reduced animation. Material controls provide press, selection and switch feedback.

## Patterns

- **Navigation:** a persistent labeled sidebar at 850 px and above; compact tooltip rail below. Session views stay mounted and retain terminal state. Focus follows the visible terminal.
- **Hosts:** searchable grid or list; explicit connect cue, favorite toggle, context menu, group filters and an actionable no-results state.
- **Vault:** password reveal, minimum-length guidance, disabled inputs while opening, progress indication and live error announcements. Never put secret values in notifications.
- **Editors:** consistent dialogs, initial field focus, validation after interaction and reveal controls on secret fields.
- **Feedback:** inline persistent notices for file/connection errors; dismissible notifications for local saves and deletes. Do not equate an open tab with an active connection.
- **Terminal:** endpoint and connection state remain visible; selected Terminal/SFTP modes are highlighted. Failed or ended sessions offer reconnect.
- **Files:** editable remote path, transfer progress, readable sizes, item count and guidance for empty directories. Destructive and overwrite operations retain confirmation.
- **Settings:** appearance, vault portability and help are grouped separately.
